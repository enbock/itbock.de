## Frontend
Das Frontend der Seite verwendet TypeScript, HTML, CSS und Web Components.
Service Worker unterstützen Offline-Fähigkeiten und Caching.
Die Spracherkennung läuft im Browser.

## Backend und Infrastruktur
Das Backend ist in TypeScript geschrieben und läuft auf AWS Lambda.
Amazon S3 wird für Assets und gespeicherte Sitzungen verwendet.
Node.js ist die Laufzeitumgebung des Backends.

## KI und Audio
OpenAI GPT übernimmt die KI-gestützte Sprachverarbeitung.
Für die Stimmenausgabe wird die Sprachsynthese Nova von OpenAI verwendet.
Audio kann zur Texterkennung transformiert werden.
